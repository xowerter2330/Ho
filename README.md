# Mega Posture — Android starter project

A simple Android checklist app for posture exercises and healthy daily habits. It stores checklist ticks and the current height entry locally on the device using SharedPreferences.

## Build an APK
1. Install Android Studio on a computer.
2. Open this folder in Android Studio.
3. Allow Gradle sync to finish (internet may be needed to download Android build dependencies).
4. Select **Build > Build APK(s)**.
5. Android Studio will show the generated APK location. Transfer it to your Android phone and install it. You may need to allow installation from that source.

## Included
- Daily posture checklist with progress bar
- School-day habits checklist
- Simple height measurement field
- Local device storage
- Safety reminder

## Notes
- This project is source code, not a prebuilt APK.
- It does not diagnose growth or promise extra height.
- The daily checklist resets based on the calendar date when the app is opened; this is a simple starter version.
